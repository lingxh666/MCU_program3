# 西安485协议开发文档

## 1. 协议概述

### 1.1 协议简介
西安协议是水质自动采样单元的通讯协议，用于上位机与采样单元之间的数据交互。协议基于Modbus RTU框架，采用寄存器地址映射方式实现数据读写。

### 1.2 通讯参数
- **波特率**: 9600 bps
- **数据位**: 8
- **停止位**: 1
- **校验位**: 无
- **物理接口**: RS485
- **帧格式**: Modbus RTU

### 1.3 功能码
- **0x04**: 读输入寄存器（监测数据、运行状态、工作参数）
- **0x06**: 写单个保持寄存器（反控）
- **0x10**: 写多个保持寄存器（时间设置）

## 2. 水质自动采样单元联网内容

### 2.1 序号1：运行状态
**描述**: A、B混匀桶工作中的状态，包括：空闲、采样、供样、留样、排空、搅拌、可扩展状态。

**寄存器地址**: 30001  
**数据类型**: 短整型  
**数量**: 1

**状态定义**:
- 1: 空闲
- 2: 采样
- 3: 供样
- 4: 留样
- 5: 排空
- 6: 搅拌
- 8~10: 可扩展混匀桶状态

**对应全局变量**: `g_State.ABucketState` 和 `g_State.BBucketState`

## 3. Modbus地址转换规则

### 3.1 地址转换说明

西安协议使用Modbus标准地址格式：

**输入寄存器（30001-39999）**：
- Modbus地址：30001
- 实际通讯地址：0x0000（30001 - 30001）
- 例如：30010 → 0x0009

**保持寄存器（40001-49999）**：
- Modbus地址：40001
- 实际通讯地址：0x0000（40001 - 40001）
- 例如：40007 → 0x0006

### 3.2 地址计算公式

```c
// 输入寄存器转换
uint16_t modbus_addr = 30001;  // Modbus地址
uint16_t actual_addr = modbus_addr - 30001;  // 实际通讯地址 = 0x0000

// 保持寄存器转换
uint16_t modbus_addr = 40001;  // Modbus地址
uint16_t actual_addr = modbus_addr - 40001;  // 实际通讯地址 = 0x0000
```
