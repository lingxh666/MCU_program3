# 大湖协议寄存器测试规范

## 测试要求

每个寄存器的测试必须包含以下内容：

| 项目 | 说明 |
|------|------|
| **寄存器地址** | Modbus地址 |
| **测试结果** | 实际读取的十六进制值 |
| **协议规定** | 大湖协议文档中的定义和取值范围 |
| **代码实现** | 代码位置和实现逻辑 |
| **变量来源** | 数据来源的全局变量或计算方式 |
| **校对结果** | ✅正确 / ⚠️部分正确 / ❌错误 |
| **备注** | 问题说明或修复建议 |

## 内部状态映射表（重要）

| 内部值 | 内部含义 | → | 协议值 | 协议含义 |

| 2 | 等待采样 | → | 9 | 等待 |

| 8 | 采样中 | → | 3 | 进样 |
| 9 | 采样暂停 | → | 3 | 进样 |
| 10 | 采样后反吹 | → | 2 | 清洗 |
| 12 | 采样完成 | → | 9 | 等待 |
| 13 | 等待送样 | → | 9 | 等待 |
| 16 | 送样前回抽 | → | 5 | 送样 |
| 19 | 送样中 | → | 5 | 送样 |
| 22 | 等待分析 | → | 8 | 分析 |
| 30 | 旋转分样盘 | → | 7 | 留样 |
| 31 | 留样瓶排空 | → | 7 | 留样 |
| 34 | 留样前回抽 | → | 7 | 留样 |
| 35 | 留前回抽完 | → | 7 | 留样 |
| 37 | 留样管存 | → | 7 | 留样 |
| 38 | 留样中 | → | 7 | 留样 |
| 39 | 留样暂停 | → | 9 | 等待 |
| 40 | 留样后回抽 | → | 7 | 留样 |
| 42 | 留样排空 | → | 7 | 留样 |
| 47 | 排空留样瓶 | → | 7 | 留样 |
| 48 | 排空瓶完成 | → | 9 | 等待 |

### 工作状态映射：内部State(0-7) → 协议状态(0-5)

**内部State定义** (freertos_app.h:324):
- 0=停止, 1=运行, 2=延时, 3=空闲, 4=维护, 5=故障, 6=启动, 7=复位中

| 内部State | 桶状态范围 | → | 协议值 | 协议含义 |
|-----------|-----------|---|--------|----------|
| 0 | - | → | 0 | 待机 |
| 1 | 4-12 | → | 2 | 运行_采样 |
| 1 | 30-48 | → | 3 | 运行_留样 |
| 1 | 其他 | → | 1 | 运行_等待 |
| 4 | - | → | 4 | 维护 |
| 5 | - | → | 5 | 故障 |

## 测试脚本要求

1. 使用Python pymodbus库进行测试
2. 输出原始十六进制数据
3. 解析并显示每个寄存器的含义
4. 保存测试日志

## 测试流程

1. 运行测试脚本获取原始数据
2. 逐个寄存器对照协议文档
3. 查看代码实现确认逻辑
4. 记录校对结果
5. 发现问题立即修复并重新测试

### 40003 仪器当前工作状态

**测试结果**: `0x0001`

**协议规定**:
- 0x0000 = 待机
- 0x0001 = 运行_等待
- 0x0002 = 运行_采样 (AB桶采样任务正在执行中)
- 0x0003 = 运行_留样 (瓶留样任务正在执行中)
- 0x0004 = 维护
- 0x0005 = 故障

**代码实现** (mb_reg_dahu.c:164-167):
```c
uint8_t current_bucket_state = (g_State.InletThreeWayValve == 2) ?
                                g_State.BBucketState : g_State.ABucketState;
dahu_set_reg(40003, dahu_map_work_state(g_State.State, current_bucket_state));
```

**映射函数** (mb_reg_dahu.c:127-147):
```c
static uint16_t dahu_map_work_state(uint8_t internal_state, uint8_t bucket_state)
{
    switch (internal_state) {
        case 0:  return 0;  // 停止 -> 待机
        case 1:  // 运行 -> 根据桶状态细分
            if (bucket_state >= 4 && bucket_state <= 12) return 2;  // 采样相关
            if (bucket_state >= 30 && bucket_state <= 48) return 3; // 留样相关
            return 1;  // 其他 -> 运行_等待
        case 4:  return 4;  // 维护
        case 5:  return 5;  // 故障
        default: return 0;
    }
}
```

**变量来源**:
- `g_State.State` - 内部仪器状态 (0=停止, 1=运行, 4=维护, 5=故障...)
- `g_State.ABucketState` / `g_State.BBucketState` - 桶内部状态 (0-50)

**校对结果**: ✅正确

**备注**: g_State.State==1(运行)，桶状态不在采样/留样范围，映射为"运行_等待"
