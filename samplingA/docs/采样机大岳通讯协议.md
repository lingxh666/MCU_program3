# 2. 接口基础说明

## 2.1. 概述

本接口设计说明书对仪器的通信连接及通信协议进行了说明。

## 2.2. 物理信道

### 2.2.1. Modbus TCP/IP（有线网络）

开放指定端口，通过Modbus TCP/IP 进行通讯

### 2.2.2. Modbus RTU（RS-485）

|  |  |  |
| --- | --- | --- |
| 信号名称 | 3 芯端子 | 备注 |
| A | 2 |  |
| B | 3 |  |
| GNG | 1 | 信号接地 |

注：确认信号线的“A”、“B”后再进行连接。如连接错误，则将无法正常通信。

## 2.3. 通信基础约定

无论物理信道是什么，最终的通讯协议都是Modbus RTU。

### 2.3.1. 通信模式

本仪器采用Master-Slave(主-从)方式，本设备为从站。

### 2.3.2. 串口参数

|  |  |
| --- | --- |
| 项目 | 规格 |
| 传输代码 | Hex Value （MODBUS RTU 模式） |
| 传输速度 | 9600 bps |

|  |  |
| --- | --- |
| 位长 | 8bit |
| 停止位 | 1bit |
| 校验位 | 无校验 |
| 流量控制 | none |
| MODBUS 站点号 | 01 |

### 2.3.3. 通信过程

通信的基本步骤

- 主设备发送请求包。
- 本仪器接收到发给自己的请求包后，根据内容发送回信包。

对主设备的限制

- 当判断已发生通信错误的情况下，需要再次发送请求包时，请保留2 秒以上的间隔。
- 包括其他从设备在内，连续发送请求包时，请保留100 毫秒以上的间隔。

### 2.3.4. 包的规格

|  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 开始 | 站地址(1Byte) | 功能码(1Byte) | 数据区(n Bytes) | | | CRC 校验(2 Bytes) | | 结束 |
|  | 8 Bits | 8 Bits | 8 Bits | … | 8 Bit | 8 Bit | 8 Bit |  |

- 开始及结束

停顿间隔为3.5 个字符时间。

- 站地址

是指单元地址。指定本仪器所设定的编号。（范围为1～247）

- 功能码

Modbus 通信协议的功能代码。本仪器对应的功能代码如下所述。

|  |  |
| --- | --- |
| 类别 | 用途 |
| Read Holding Registers（3） | 主设备读取时使用本仪器的第40001～40030 号寄存器的数据。 |
| Preset Single Registers（6） | 主设备设定时使用本仪器的第40001～40030 号寄存器的数据。 |
| Preset Multiple Registers（16） |

注释

当接收到上述功能代码以外的功能代码时，则返回异常应答的不正当功能代码(1)。

- 数据区

数据区内容随着代码不同而不同，看具体需要。

- CRC

用于校验数据的有效性。

CRC 校验发现错误时，无任何反馈。

# 4. 附件--通讯接口调用说明

## 4.1. 采样器功能简介

本AB 桶采样器可单独做为单一功能瞬时留样采样器使用，也可以作为结合多模式采样、供样、多模式留样等复杂功能为一体的环保专用采样器使用。

**采样：**将水样从外部管路取到A、B 桶的过程； **送样：**将水样从A、B 桶供应到分析仪的过程； **桶留样：**将水样从A、B 桶保存到采样瓶的过程；

**瞬时留样：**将水样从外部管路（绕过A、B 桶）直接保存到采样瓶的过程；**桶排空：**将水样从A、B 桶排空至仪器外部的过程；

**瓶排空：**将水样从1~24 个留样瓶排空至仪器外部的过程；

**加固定剂：**在留样过程中，根据指定比例，将指定将固定剂加入到正在留样的瓶中的过程；

## 4.2. 环保专用 AB 桶多模式留样功能

### 4.2.1. 设置过程

操作采样器触摸屏界面，依次进行如下设置：

- 高级设置>通讯设置>数采协议 设置为“数采仪01”；
- 采样设置>桶采样相关>采样模式，根据需求可设置为：时间等比、排放等比、流量比例、流量触发、开关触发、通讯触发；
- 留样设置>瓶留样参数>留样模式，根据需求可设置为：同步留样、超标留样、循环留样、通讯触发；

### 4.2.2. 采样过程

当采样模式设置为“通讯触发”时，则采样器采样由外部通讯设备（如数采仪）控制，数采仪可多次发送AB

桶采样指令（见[4.6 触发AB 桶采样](#_bookmark41)），触发一次AB 桶混样，此模式下，无桶切换（采样）周期限制；

设置为其他模式时，采样器将以不同的采样模式（时间等比、排放等比、流量比例、流量触发、流量跟随、开关触发），当设定模式的采样条件达到，将水样从外部管路采集到A 或B 桶，在一个设定的桶切换（采样）周期后，切换到下一个桶采样；

### 4.2.3. 送样过程

当留样模式设置为“通讯触发”时，则采样器送样由外部通讯设备（如数采仪）控制，数采仪可发送 AB 桶送样指令（见[4.7 触发AB 桶送样](#_bookmark43)）来触发采样器从A 或B 桶执行一次送样过程；

当设置为其他模式时，在切换采样桶的的同时采样器自动将当前桶内水样传送到外部水质分析仪取样池，当达到设定的送样量后，可由采样器自动启动（输出开关量）外部分析仪分析，也可以由数采来读取采样器桶水样是否准备好状态（见[4.4 读取蓄水桶水样是否准备好状态](#_bookmark39)），一旦数采读取到桶水样准好信号变为有效，则立即启动外部分析仪分析；

### 4.2.4. 留样过程

当留样模式设置为“通讯触发”时，则采样器留样由外部通讯设备（如数采仪）控制，采样器在等待外部水质分析仪分析的过程中（设定的“仪表分析时间”等待周期时间内），数采可发送AB 桶留样指令（见[4.8 启动一 次AB 桶留样](#_bookmark44)）来触发采样器从A 或B 桶执行一次留样过程；

当设置为其他模式时，送样过程结束，成功启动外部分析仪分析后，根据设置的留样模式，执行如下过程；

- 超标留样：采样器等待外部所有水质分析仪分析完成，当设定的等待周期时间达到，采样器根据数采传输来的各个水质分析仪的测量值（见 4.5 现场水质仪表测量值设置），与内部设定的每个水质因子对应的超标阈值比较，判断是否有一个或多个水质因子超标，若超标则执行一次AB 桶留样过程，若所有因子超标参数均设置为“停用”，则根据数采超标同步信号进行超标留样；
- 循环留样：采样器等待外部所有水质分析仪分析完成，当设定的等待周期时间达到，采样器立即执行一次AB 桶留样过程；
- 同步留样：采样器等待外部所有水质分析仪分析完成，在设定的等待周期时间内，等待外部开关输入信号，当检测到开关输入有效，采样器立即执行一次AB 桶留样过程；

### 4.2.5. 排空过程

接上一个过程，如果上一个过程采样器执行了一次AB 桶留样，则留样结束后，执行一次AB 桶排空过程，若未执行过AB 桶留样，等待水质分析仪分析过程结束后，执行一次AB 桶排空过程；

## 4.3. 瞬时留样功能

在任意留样模式下，数采可以写“直接瞬时留样”寄存器触发一次瞬时留样过程；

采样器随时等待瞬时留样指令（见[4.9 启动一次瞬时留样](#_bookmark45)），一旦接收到触发留样指令，采样器在未执行送样、留样的情况下立即执行一次瞬时留样过程；

## 4.4. 读取蓄水桶水样是否准备好状态

## 4.16. 远程复位或者启动设备

- 远程复位设备，往40429 寄存器写0x0001：数采发送：01 06 01 AD 00 01 D8 17

需要注意的是，远程复位类似断电重启设备，清空A/B 桶并重新开始采样、送样、留样流程，但是不会复位分样盘（本地复位按钮会复位分样盘）

- 远程停止设备，往40429 寄存器写0x0003：数采发送：01 06 01 AD 00 03 59 D6

## 4.17. 远程指令接收、执行及完成状态反馈

对于部分远程控制寄存器，40535~40537、40540~40543：

- 采样器接收到写指令后，将本寄存器最高位置1，即0x81/0x82…，当读取到此值时表明指令被接收
- 当指令被真正执行以后，将本寄存器次高位置1，即0xC1/0xC2…，当读取到此值时表明指令被执行
- 在指令完成之后，自动清零该寄存器值
- 在寄存器清零以前，禁止写入新的值。

备注：部分指令启动执行比较快时，可能数采仪无法捕捉到接收指令但是并未执行的状态。
