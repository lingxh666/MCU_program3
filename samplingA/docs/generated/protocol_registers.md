# 协议寄存器对照表（以源码为准）

说明：
- 地址按源码中的 Modbus 地址书写（Dayue 为 0-based；其余协议按 40001/30001 绝对地址）。
- `uint16` 为大端 16 位；`float32` 由 2 个寄存器组成，大端字节序。
- 时间多使用 BCD 码或年/月/日/时/分/秒分寄存器。

### 1.2 超标留样信息（0x0051-0x00C6）
- 0x0051-0x0056：留样时间（BCD 年/月/日/时/分/秒）
- 0x0057：执行结果
- 0x0058：失败原因
- 0x0059：留样瓶数
- 0x005A：启用因子个数
- 0x005B-0x0084：因子 1-6（每因子 7 寄存器：类型、值 float、下限 float、上限 float）
- 0x0085-0x00C6：瓶 1-6 详情（每瓶 11 寄存器：瓶号、结果、体积、失败原因、序号、时间BCD）

### 1.3 普通留样信息（0x00C7-0x00DC）
|地址|R/W|说明|单位/类型|
|---|---|---|---|
|0x00C7-0x00C8|R|保留|uint16|
|0x00C9-0x00CE|R|留样时间（BCD）|BCD|
|0x00CF|R|结果|uint16|
|0x00D0|R|失败原因|uint16|
|0x00D1|R|起始瓶号|uint16|
|0x00D2|R|瓶数|uint16|
|0x00D3|R|留样体积|mL, uint16|
|0x00D4|R|留样模式|uint16|
|0x00D5|R|触发条件（预留）|uint16|
|0x00D6|R|是否加药（预留）|uint16|
|0x00D7|R|药剂类型（预留）|uint16|
|0x00D8|R|保留|uint16|
|0x00D9-0x00DC|R|样品编号|uint16[4]|

### 1.4 瞬时留样/弃样记录
- 0x00DD-0x00E6：瞬时留样时间（BCD）、结果、失败原因、起始瓶号、瓶数、体积
- 0x00E7-0x00F4：弃样时间（BCD）、结果、失败原因、起始瓶号、瓶数、样品编号

### 1.5 其他参数与配置
|地址|R/W|说明|单位/类型|
|---|---|---|---|
|0x00F5-0x0129|R|保留|uint16|
|0x012A-0x012F|R|制水完成时间（保留）|BCD|
|0x0130-0x015F|R/W|因子阈值配置（6因子*8寄存器）|uint16/float32|
|0x0160-0x017F|R|保留|uint16|
|0x0180-0x0197|R/W|采样参数区|uint16|
|0x0198-0x01AC|R/W|留样参数区|uint16|
|0x01AD|W|远程控制：1复位/2启动/3停止/4恢复|uint16|
|0x01AE|W|复位瓶信息：1-24单瓶，0xFF全部|uint16|
|0x01B0-0x01E0|R/W|因子数据（10因子*3寄存器）|uint16/float32|
|0x01E1-0x01E6|R|系统时间（年/月/日/时/分/秒）|uint16|
|0x01E7-0x0215|R|门禁卡号/动态密码/设备信息|uint16|
|0x0216-0x0218|W|桶动作：1采样/2排空/3送样|uint16|
|0x0219|W(3寄存器)|留样触发：起始瓶/数量/类型|uint16|
|0x021C|R/W|读：送样就绪；写：瞬时留样瓶数|uint16|
|0x021D|R|送样同步信号（当前读回0）|uint16|
|0x021E|R|超标信号（阈值判定）|uint16|
|0x021F-0x0220|R|流量值|float32|
|0x0221-0x0258|R|保留/授权区|uint16|

采样参数区（0x0180-0x0187）写入时：
- 协议模式映射：值 2→内部 1（时间等比），6→内部 2（通讯触发），5→内部 3（开关触发），其他回退 1。

时间设置：
- 0x01DA（7 寄存器）写入年月日时分秒与 cmd=1 时更新 RTC。

### 1.6 留样触发（0x0219，3寄存器）
- `startBottle` / `bottleCount` / `type`
- type=1 A桶，2 B桶，3 AB自动，4 瞬时留样，5 瓶盘排空

- 40475（7寄存器）：RTC 时间设置
- 40535/40536/40537：A/B/自动桶动作（1采样/2排空/3送样）
- 40538（3寄存器）：留样触发（起始瓶/数量/类型）
- 40541：瞬时留样（瓶数）
