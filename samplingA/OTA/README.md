# MQTT OTA固件升级工具

## 功能特点

- 友好的图形界面（GUI）
- 支持选择bin固件文件
- 实时显示升级进度
- 完整的日志记录
- 自动重试机制
- 简单的校验和验证

## 环境要求

- Python 3.7+
- paho-mqtt 库

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行程序

### 方法1：直接运行
```bash
python main.py
```

### 方法2：模块方式运行
```bash
python -m OTA
```

## 使用说明

1. **设备配置**
   - 输入设备编号（默认：CYJ_2512121H1001B）

2. **选择文件**
   - 点击"选择文件"按钮
   - 选择要升级的.bin固件文件
   - 程序会自动计算文件大小和校验和

3. **开始升级**
   - 点击"开始升级"按钮
   - 确认升级信息
   - 程序会自动连接MQTT服务器并发送数据

4. **查看进度**
   - 进度条显示当前升级进度
   - 日志窗口显示详细的操作信息

5. **其他功能**
   - 停止：中断当前升级
   - 清空日志：清除日志窗口内容
   - 关于：查看程序信息

## 协议说明

### MQTT服务器配置
- 服务器：124.222.59.221
- 端口：1883
- QoS：1

### 通信主题
- 命令主题：CYJSET（发送升级开始指令）
- 数据主题：CYJOTA（发送固件数据包，同时通过此主题接收设备ACK）

### 数据格式

#### 升级开始指令
```
ML307OTA_<设备编号>_<校验和>CRC
```
示例：`ML307OTA_CYJ_2512121H1001B_19646541CRC`

#### 数据包格式
二进制格式，每包2048字节：
```
[包头:2字节][包序号:2字节][总包数:2字节][数据长度:2字节][校验和:1字节][数据:2048字节]
```
- 包头：0xAA55
- 校验和：简单的8位累加和

#### ACK格式
```
ACK_<包序号>_<状态>
```
示例：`ACK_1_OK`

## 注意事项

1. 确保网络连接正常，能够访问MQTT服务器
2. 升级过程中不要关闭程序
3. 如果升级失败，可以重新尝试
4. 程序支持自动重试，默认最大重试3次

## 故障排除

1. **无法连接MQTT服务器**
   - 检查网络连接
   - 确认服务器地址和端口正确

2. **文件选择失败**
   - 确保选择的是有效的.bin文件
   - 检查文件是否存在

3. **升级失败**
   - 查看日志窗口的错误信息
   - 确认设备是否正常响应
   - 重新尝试升级
