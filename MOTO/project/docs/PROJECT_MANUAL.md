# AT32F421 双步进电机控制系统 - 项目手册

## 项目概述

本项目基于雅特力AT32F421F8P7微控制器，实现双路步进电机的PWM调速控制、电流监测和Modbus RTU通信功能。

### 主要功能

- 双步进电机独立控制（PWM+方向）
- 软启动/软停止（加减速控制）
- 电机电流实时监测（INA180A2IDBVR）
- 故障诊断（过流/欠流检测）
- LED状态指示
- Modbus RTU从站通信（RS485）
- 2.5V基准电压ADC校准

### 系统参数

| 参数 | 值 |
|------|-----|
| MCU | AT32F421F8P7 @ 72MHz |
| 步进电机步距角 | 1.8° |
| 细分数 | 16 (固定) |
| 脉冲数/转 | 3200 |
| RPM范围 | 1-1000 |
| PWM频率范围 | 53-53333 Hz |
| 默认加速度 | 500 RPM/s |
| 通信接口 | USART2 @ 115200bps |
| 电流检测 | INA180A2IDBVR (增益50x) |

### 主循环结构

```c
while(1) {
    // 1. 电机加减速更新：已移入TMR6 1kHz中断
    //    (TMR6_GLOBAL_IRQHandler -> MotorUpdate)

    // 2. Modbus RTU处理 (非阻塞，主循环唤醒后处理)
    Modbus_Process();

    // 3. 1秒任务 (由TMR3中断标志触发)
    if (g_tmr3_update_flag) {
        MotorUpdateLEDIndicator();  // LED状态更新
        MotorMonitorUpdate();       // 电流监测更新
        Modbus_UpdateHoldingRegs(); // Modbus寄存器更新
    }

    // 4. 空闲睡眠，等待下一次中断唤醒
    __WFI();
}
```

## 电流监测模块 (motor_monitor)

### 硬件配置

- **电流传感器**: INA180A2IDBVR
- **增益**: 50 V/V
- **采样电阻**: 0.02Ω
- **最大电流**: 2A

### 电流计算

```
V_sense = I_motor × 0.02Ω
V_out = V_sense × 50 = I_motor × 1
I_motor (mA) = V_out (mV)

ADC测量:
V_out_measured = ADC_value × (Vref_2V5 / 4095)
I_motor = ADC_value × 2500 / 4095 (mA)
```

### ADC通道配置

| 序列 | 通道 | 引脚 | 功能 |
|------|------|------|------|
| 1 | CH5 | PA5 | 2.5V基准电压 |
| 2 | CH9 | PB1 | 电机1电流 |
| 3 | CH6 | PA6 | 电机2电流 |

### 滤波算法

```
1. 收集1秒内所有ADC采样 (约1000个样本)
2. 去除20%最大值
3. 去除20%最小值
4. 中间60%取平均值
```

### 诊断逻辑

| 电机转动 | 电流 | 状态 |
|----------|------|------|
| 是 | > 10mA | RUNNING (正常) |
| 是 | ≤ 10mA | FAULT (欠流故障) |
| 否 | > 10mA | FAULT (过流故障) |
| 否 | ≤ 10mA | STOPPED (正常) |

### 核心API

## Modbus RTU通信 (重点)

### 通信参数

| 参数 | 值 |
|------|-----|
| 协议 | Modbus RTU |
| 接口 | RS485 (半双工，自动收发) |
| 波特率 | 115200bps |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验 | 无 |
| 从站地址 | 0x01 或 0x02 (PA1引脚检测) |

### 从站地址检测

```
上电时读取PA1引脚状态:
- PA1 = 高电平 → 从站地址 = 0x01
- PA1 = 低电平 → 从站地址 = 0x02
```

### 支持的功能码

| 功能码 | 名称 | 操作 |
|--------|------|------|
| 0x03 | 读保持寄存器 | 读取状态/配置 |
| 0x06 | 写单寄存器 | 写单个控制参数 |
| 0x10 | 写多寄存器 | 批量写入参数 |

### 异常码

| 异常码 | 名称 | 说明 |
|--------|------|------|
| 0x01 | 非法功能 | 不支持的功能码 |
| 0x02 | 非法数据地址 | 寄存器地址超出范围 |
| 0x03 | 非法数据值 | 参数值超出允许范围 |
| 0x04 | 从站故障 | 设备内部故障 |

## Modbus寄存器映射详解

### 控制寄存器区域 (0x0000-0x0007)

**读写访问，用于设置电机参数和控制命令**

#### 电机1控制寄存器 (0x0000-0x0003)

| 地址 | 名称 | 数据类型 | 范围 | 说明 |
|-----|------|----------|------|------|
| 0x0000 | M1_TARGET_RPM | uint16 | 1-1000 | 电机1目标转速(RPM) |
| 0x0001 | M1_DIRECTION | uint16 | 0-1 | 0=CW顺时针, 1=CCW逆时针 |
| 0x0002 | M1_COMMAND | uint16 | 0-3 | 控制命令 |
| 0x0003 | M1_ACCELERATION | uint16 | 10-2000 | 加速度(RPM/s) |

#### 电机2控制寄存器 (0x0004-0x0007)

| 地址 | 名称 | 数据类型 | 范围 | 说明 |
|-----|------|----------|------|------|
| 0x0004 | M2_TARGET_RPM | uint16 | 1-1000 | 电机2目标转速(RPM) |
| 0x0005 | M2_DIRECTION | uint16 | 0-1 | 0=CW顺时针, 1=CCW逆时针 |
| 0x0006 | M2_COMMAND | uint16 | 0-3 | 控制命令 |
| 0x0007 | M2_ACCELERATION | uint16 | 10-2000 | 加速度(RPM/s) |

#### 控制命令定义 (M1_COMMAND / M2_COMMAND)

| 值 | 命令 | 说明 |
|----|------|------|
| 0x0000 | CMD_NOOP | 无操作，不改变电机状态 |
| 0x0001 | CMD_RUN | 运行电机（使用当前TARGET_RPM和DIRECTION） |
| 0x0002 | CMD_STOP | 软停止（平滑减速到0） |
| 0x0003 | CMD_IMMEDIATE_STOP | 立即停止（急停） |

#### 系统配置寄存器 (0x0040)

| 地址 | 名称 | 数据类型 | 范围 | 说明 |
|-----|------|----------|------|------|
| 0x0040 | SLAVE_ADDR | uint16 | 1-247 | 从站地址（需重启生效） |

### 状态寄存器区域 (0x0100-0x0109)

**只读访问，反映电机当前状态**

#### 电机1状态寄存器 (0x0100-0x0104)

| 地址 | 名称 | 数据类型 | 说明 |
|-----|------|----------|------|
| 0x0100 | M1_CURRENT_RPM | uint16 | 电机1当前实际转速(RPM) |
| 0x0101 | M1_CURRENT_MA | uint16 | 电机1当前电流(mA) |
| 0x0102 | M1_STATE | uint16 | 电机1运行状态 |
| 0x0103 | M1_STATUS | uint16 | 电机1诊断状态 |
| 0x0104 | M1_FAULT_CODE | uint16 | 电机1故障代码 |

#### 电机2状态寄存器 (0x0105-0x0109)

| 地址 | 名称 | 数据类型 | 说明 |
|-----|------|----------|------|
| 0x0105 | M2_CURRENT_RPM | uint16 | 电机2当前实际转速(RPM) |
| 0x0106 | M2_CURRENT_MA | uint16 | 电机2当前电流(mA) |
| 0x0107 | M2_STATE | uint16 | 电机2运行状态 |
| 0x0108 | M2_STATUS | uint16 | 电机2诊断状态 |
| 0x0109 | M2_FAULT_CODE | uint16 | 电机2故障代码 |

#### 电机状态值 (M1_STATE / M2_STATE)

| 值 | 状态 |
|----|------|
| 0 | 停止 (STOPPED) |
| 1 | 加速中 (ACCELERATING) |
| 2 | 运行中 (RUNNING) |
| 3 | 减速中 (DECELERATING) |

#### 诊断状态值 (M1_STATUS / M2_STATUS)

| 值 | 状态 |
|----|------|
| 0 | 停止 (STOPPED) - 电机未运行且无电流 |
| 1 | 运行 (RUNNING) - 电机运行且电流正常 |
| 2 | 故障 (FAULT) - 电流与运行状态不匹配 |

#### 故障代码值 (M1_FAULT_CODE / M2_FAULT_CODE)

| 值 | 故障类型 | 说明 |
|----|----------|------|
| 0 | 无故障 | 正常状态 |
| 1 | 欠电流故障 | 电机运行但无电流 |
| 2 | 过电流故障 | 电机停止但仍有电流 |

## Modbus自动运行机制

### 方案说明

为简化控制流程，系统实现了**参数写入自动触发运行**的机制：

```
当写入以下寄存器时，如果对应的COMMAND寄存器值为CMD_RUN(0x0001)，
系统会自动执行MotorRun()操作：

- 写入 M1_TARGET_RPM (0x0000)
- 写入 M1_DIRECTION (0x0001)
- 写入 M2_TARGET_RPM (0x0004)
- 写入 M2_DIRECTION (0x0005)
```

### 使用流程

#### 方法1: 先设置参数，后发送命令

```
步骤1: 写入转速和方向
步骤2: 写入COMMAND=CMD_RUN触发执行
```

#### 方法2: 一次命令完成所有设置（推荐）

```
使用功能码0x10（写多寄存器），同时写入：
- TARGET_RPM
- DIRECTION
- COMMAND=CMD_RUN

写入完成后自动执行MotorRun()
```

### 示例

**设置电机1: 150 RPM, 顺时针, 立即运行**

方法1（两次写入）:
```
写单寄存器(0x06): 地址0x0000, 值150 (设置转速)
写单寄存器(0x06): 地址0x0001, 值0 (设置方向)
写单寄存器(0x06): 地址0x0002, 值1 (触发运行)
```

方法2（一次写入）:
```
写多寄存器(0x10): 地址0x0000, 数量3, 数据[150, 0, 1]
                 (转速=150, 方向=CW, 命令=RUN)
```

## CRC计算

### 硬件CRC实现

系统使用AT32F421内置的硬件CRC模块计算Modbus CRC16：

```c
// 初始化配置
crc_init_data_set(0x0000FFFF);        // 初始值
crc_poly_size_set(CRC_POLY_SIZE_16B); // 16位多项式
crc_poly_value_set(0x8005);            // Modbus多项式
crc_reverse_input_data_set(CRC_REVERSE_INPUT_BY_BYTE);
crc_reverse_output_data_set(CRC_REVERSE_OUTPUT_DATA);
```

### CRC16-MODBUS参数

| 参数 | 值 |
|------|-----|
| 多项式 | 0x8005 (x^16 + x^15 + x^2 + 1) |
| 初始值 | 0xFFFF |
| 反向输入 | 按字节反向 |
| 反向输出 | 是 |
| 结果异或 | 0x0000 |

### 使用示例

```c
uint16_t crc = CRC16_MODBUS(data_buffer, data_length);
uint8_t valid = CRCCheck(receive_buffer, receive_length);
```

## 使用说明

### 硬件连接

1. **电源**: 提供12V-24V电机电源和5V逻辑电源
2. **电机驱动器**: 连接PWM/DIR信号到驱动器输入
3. **RS485**: 连接A/B线到485总线
4. **从站地址**: 上电前设置PA1电平选择地址

### 配置步骤

1. 设置PA1引脚电平（高=地址1，低=地址2）
2. 上电，系统自动检测从站地址
3. Modbus主机发送控制命令
4. 电机按命令运行，状态实时反馈

### 常用命令序列

#### 启动电机1到500RPM，顺时针
```
1. 写0x0000 = 500 (设置转速)
2. 写0x0001 = 0 (顺时针)
3. 写0x0002 = 1 (运行命令)
或一次完成: 写0x0000开始3个寄存器 [500, 0, 1]
```

#### 停止电机1
```
写0x0002 = 2 (软停止)
或 写0x0002 = 3 (立即停止)
```

#### 读取电机状态
```
读0x0100开始5个寄存器 (返回RPM, 电流, 状态, 诊断, 故障码)
```

## 故障排查

### 电机不转

1. 检查从站地址是否匹配
2. 检查COMMAND寄存器是否为CMD_RUN
3. 检查TARGET_RPM是否在有效范围(1-1000)
4. 检查PWM输出是否正常

### 通信无响应

1. 检查波特率设置(115200bps)
2. 检查RS485接线(A/B线)
3. 检查CRC是否正确
4. 检查从站地址检测(PA1状态)

### 电流读数为0

1. 检查INA180供电
2. 检查采样电阻连接
3. 检查ADC通道配置
4. 等待1秒让ADC数据累积

### 电机故障报警

- **欠流故障(代码1)**: 电机运行但电流为0 → 检查电机连接
- **过流故障(代码2)**: 电机停止但有电流 → 检查驱动器
